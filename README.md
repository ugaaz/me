# Aziiz Guuleed | Guuleed Green

Personal website for **Aziiz Guuleed**, environmental scientist, researcher and senior lecturer. The public brand is **Guuleed Green**.

**Tagline:** Ideas, Evidence & Solutions for a Resilient Somalia  
**Preferred domain:** [guuledgreen.com](https://guuledgreen.com)

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
